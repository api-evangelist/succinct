# Succinct

> Succinct is an applied cryptography company building zero-knowledge proof
> infrastructure. Its flagship product is SP1, an open-source zkVM that proves
> correct execution of RISC-V programs, and the Succinct Prover Network (SPN), a
> decentralized on-chain marketplace on Ethereum that coordinates provers to
> generate ZK proofs for any software. The network is powered by the PROVE token.
> The programmatic surface is a gRPC API (not REST/OpenAPI); developers integrate
> in Rust via the SP1 SDK and authenticate to the network with a Secp256k1 key pair.

This llms.txt was generated by the API Evangelist enrichment pipeline from the
Succinct public developer surface and the artifacts in this repository.

## Products
- [SP1 zkVM](https://docs.succinct.xyz/docs/sp1/introduction): open-source RISC-V zero-knowledge virtual machine
- [Succinct Prover Network](https://docs.succinct.xyz/docs/provers/introduction): decentralized proving marketplace on Ethereum
- [Explorer](https://explorer.succinct.xyz/): prover network explorer / deposit UI
- [OP Succinct](https://github.com/succinctlabs/op-succinct): ZK proving engine for the OP Stack
- [SP1 Helios](https://github.com/succinctlabs/sp1-helios): on-chain Ethereum light client built with SP1
- [PROVE token](https://docs.succinct.xyz/docs/protocol/prove/overview): network economic token
